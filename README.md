# 💧 Su Stok Takip Sistemi (Water Stock Tracking System)

Su stok seviyelerini verimli bir şekilde yönetmek, izlemek ve kontrol etmek amacıyla **ASP.NET MVC**, **C#** ve **MSSQL** teknolojileri kullanılarak geliştirilmiş web tabanlı stok yönetim uygulaması.

---

## 📌 Özellikler

* **Stok Yönetimi:** Su ürünlerinin stok miktarlarını anlık olarak ekleme, güncelleme ve silme.
* **Veritabanı Mimarisi:** MSSQL üzerinde kurgulanmış ilişkisel veritabanı tasarımı.
* **Kullanıcı Dostu Arayüz:** Stok takibini kolaylaştıran sade ve dinamik kullanıcı arayüzü.
* **CRUD İşlemleri:** C# ve ASP.NET MVC mimarisiyle yazılmış veri işleme mantığı.

---

## 🛠️ Kullanılan Teknolojiler

* **Backend:** C#, ASP.NET MVC (.NET Framework)
* **Veritabanı:** Microsoft SQL Server (MSSQL)
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript, Toastr
* **Araçlar & Versiyon Kontrolü:** Visual Studio, Git, GitHub
